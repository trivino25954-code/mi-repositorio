# Mi Portafolio

Mi portafolio personal es una página web donde muestro mi perfil, proyectos y habilidades como aprendiz de Análisis y Desarrollo de Software. Está pensado para presentar mi trabajo de forma ordenada, clara y profesional.

## Descripción

- Presento información personal y académica.
- Destaco proyectos y ejercicios desarrollados durante el programa.
- Incluyo medios de contacto para futuras oportunidades laborales o colaboraciones.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Cómo ver el proyecto

1. Clona este repositorio en tu computadora.
2. Abre la carpeta del proyecto.
3. Ejecuta un servidor local para visualizar la página.

```bash
git clone https://github.com/tu-usuario/mi-portafolio.git
cd mi-portafolio
python -m http.server 8000
```

Luego abre tu navegador en `http://localhost:8000`.

## Estructura de carpetas

- `css/` — estilos del sitio web.
- `img/` — imágenes y recursos gráficos.
- `js/` — lógica del portafolio.
- `planeacion/` — documentos de planificación y etiquetas.
- `respaldos/` — copias de seguridad del proyecto.
- `index.html` — estructura principal de la página.
